当用户提到自己日常浏览器中正在打开的标签页、网页内容、登录状态，或者选择 `/标签-...` 时，优先使用 `browser-bridge` 插件提供的 MCP 工具（如 `list_tabs`、`get_active_tab`、`read_page_content`）直接连接并读取用户当前 Chrome / Edge 浏览器，不要擅自新建空白浏览器或绕开插件去猜测页面内容。只读取信息时优先使用 `read_page_content`；执行连续多步页面操作（如滚动、点击、等待弹窗、再点击/输入）时优先合并到 `run_steps`（配合 `includeSnapshot: true` 或 `includeContent: true`）一次完成以大幅提速。任务完成后默认保持调试模式与虚拟鼠标常驻待命（不要主动调用 `detach_debugger`），以保证后续操作零延迟响应；仅当用户明确要求关闭调试模式时才调用 `detach_debugger`。
